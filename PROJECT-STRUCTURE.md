# Sleeve source layout

- Browser-side Find Music source modules: `src/features/find-music/ui/`. Keep modules small and focused for editing and testing.
- Runtime Find Music bundle: `find-music-bundle.js`. This is generated by `node scripts/build-find-music-bundle.js` and is the only Find Music UI script loaded from `index.html`.
- Electron main-process modules remain separate: they own different IPC handlers and security-sensitive responsibilities. They are deliberately not concatenated into renderer code.
- Tests live under `tests/`; run all current tests with `npm test`. `tests/run-all.js` launches each test in its own Node process so globals and asynchronous cleanup from one test cannot pollute another.
- Historical root-level `.bak` snapshots are kept under `backups/root-snapshots/`. The complete pre-migration copy is in `backups/structure-consolidation-20261027T233923Z/`.

When editing Find Music UI code, edit the source modules under `src/features/find-music/ui/`, then regenerate the runtime bundle. Do not hand-edit the generated bundle.
